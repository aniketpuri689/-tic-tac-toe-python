# Tic Tac Toe Master 🎮

A Python-based Tic Tac Toe game developed using Tkinter in VS Code.

## Features
- Play with Friends mode
- Play with Computer mode
- GUI-based interactive gameplay
- Winner and draw detection
- Move recording
- Restart functionality
- Logic-based move selection
- Strategic computer gameplay using:
  - winning move detection
  - blocking moves
  - center control
  - corner prioritization

## Used
- Python
- Tkinter

## About the Project
This project was created as part of self-learning in Python programming, GUI development, and game logic design. The AI mode was designed using conditional logic and strategic move evaluation.
